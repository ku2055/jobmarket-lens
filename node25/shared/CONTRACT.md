# V2.5 integration contract

Independent app under node25/; V2 frontend/ must remain unchanged. ESM Node 22.20, React/Vite UI.
API POST /api/query accepts JSON {protocolVersion:'2.5',datasetVersion?:string,requestId:string,sourceMode:'combined'|'upstream'|'local',view:'overview'|'records'|'compare'|'skills'|'evidence',filter:{search?:string,companyIds?:string[],occupationIds?:string[],skillIds?:string[],countries?:string[],arrangements?:string[],availability?:'open'|'all'|'closed'},page?:{offset:number,limit:number},cohortA?:Filter,cohortB?:Filter}.
Filters AND across fields, OR within each selected list; skillIds ALL required. Open means local_observed or upstream_reported_open. Default open. Explicit all includes closed/unknown. Null remains unknown.
GET /api/catalog returns {protocolVersion:'2.5',datasetVersion,counts,companies:[{id,name}],occupations:[{id,name}],skills:[{id,name}],sources,asOf,methods,limitations}.
All query responses {protocolVersion:'2.5',datasetVersion,requestId,sourceMode,matchedCount,contributorHash,elapsedMs,data}.
Overview data {companyCount,analyzedTextCount,eligiblePayCount,unknownCountryCount,unknownArrangementCount,pay:{count,medianLow,medianHigh,currency:'USD',basis:'annual advertised range bounds'},companies:[{id,label,count}],occupations:[{id,label,count}],countries:[{id,label,count}],arrangements:[{id,label,count}],matrix:{companies:[{id,label}],occupations:[{id,label}],cells:[{companyId,occupationId,count}],otherCount:number},skills:[{id,label,count,share}],coverage:{total,shownCompanies,shownOccupations}}. Top dimension results capped visibly; exact matchedCount always retained.
Records data {rows:public posting objects,total,offset,limit,hasMore}; GET detail through view records filtered search not exact; optional POST /api/detail {sourceMode,id,datasetVersion}. Records row may include all sanitized public V2 posting fields, at most100 rows.
Skills data {skills:[{id,label,count,share}],analyzedTextCount,coMentions:[{a,b,count}],basis:string}.
Evidence data {counts,sources,methods,limitations,coverage:{analyzedTextCount,unknownCountryCount,unknownArrangementCount,eligiblePayCount},sourceModes:counts}.
Compare data {a:{count,hash,companyCount,eligiblePayCount,skills:[{id,label,count,share}]},b:same,overlap,onlyA,onlyB,differences:[{id,label,aCount,bCount,aShare,bShare,delta}] (delta=100*(aShare-bShare), A-minus-B percentage points)}; A/B filters frozen in browser plus dataset/source; server resolves exact IDs and hashes.
POST /api/export same query envelope: CSV server streaming all selected public records (not browser full-table); safe spreadsheet cells; contributor identity header X-Contributor-Hash; dataset header X-Dataset-Version.
GET /api/health returns dataset/version/readiness. GET /api/admin returns 401 unless authenticated; admin API handled by coordinator.
Frontend admin login POST /api/admin/login {password}; secure HttpOnly SameSite=Strict cookie on success; DELETE /api/admin/login logout. GET /api/admin returns {deployment:{...},collection:{counts,sources,lastSnapshot,scheduled:false,runs:[],limitations:[]},traffic:{configured:boolean,source:string,visitors:number|null,pageViews:number|null,routes:[],countries:[],limitations:[]},runtime:{...}}. Missing analytics honestly unconfigured. Auth never goes to localStorage. Admin not public-indexed.

Data lane creates store/release.json + store/postings.parquet (all modes) and optional other parquet files; release JSON {datasetVersion,counts,catalog:{companies,occupations,skills,sources},asOf,methods,limitations,files:[{path,sha256,bytes}],collection:{...}}. Parquet columns: mode VARCHAR,id VARCHAR,companyId VARCHAR,title VARCHAR,occupationId VARCHAR nullable,level VARCHAR nullable,arrangement VARCHAR nullable,availability VARCHAR,hasDescription BOOLEAN nullable,eligiblePay BOOLEAN,annualLow DOUBLE nullable,annualHigh DOUBLE nullable,countries VARCHAR[],skillIds VARCHAR[],detailJSON VARCHAR (full strict public posting JSON). No descriptions/raw/private paths. (mode,id) unique. Hash verified at startup. SQL aliases quote camelCase columns.
